# 识图记录与配置说明

## 可核对的自然语言中间记录

用户要求查看识别之后的自然语言时，提供这些内容，而不是隐藏推理或笼统描述。若先前未实际保存独立记录，明确这是依据现有证据整理的记录，不声称找回了原始中间文件。

```text
资料与版本：文件名、页/照片编号、用户修订版本。
读取方式：CAD实体解析／软件目视／SCADA照片目视。
绘图范围：哪些池、阶段、设备、上下游。
区域：编号、名称、所属组、相对位置、证据状态。
墙体与孔洞：连接双方、类型、方向，尺寸/标高若可读。
设备：原编号、名称、所在区域、现有/新增/建议、位置依据。
显示项：参数、所属设备或出口、是否确认物理仪表。
连接：起点、终点、经过阀组/过水口、方向、证据。
简化：合并了什么图形，仍保留什么真实数量。
待核实：缺少的信息及影响。
```

例如：资料确认有5台计量泵和4项出口流量；用户确认另增1台泵至新建磁混凝1#池；既有泵架内部切换接法待核实，采用阀组功能框。这样的记录可以核对数量与关系，但不是施工管路设计。

## 从定稿写说明

以最新定稿和用户确认的事实为依据，分现有、新增、替换、利旧。优先复核数量、位置区域、去向、合并符号含义及显示项是否等于实物。

用户给出的模板句式可以沿用，但不要把模板中的厂规模、池组数量、DN口径、厂家直管段要求、型号、新增或利旧状态机械套入另一张图。用户直接确认的项目事实可保留，即使简图没有文字；资料缺失的参数不补造。

DO 监测点数不直接等于独立控制区数。多个参数写在同一符号后不直接等于双通道硬件；同一出口显示与泵显示不直接等于两套仪表。

说明放在用户的 Word 文本或可复制文字中，不再给简图附加说明侧栏。涉及待核实项时简洁说明影响，不复制整个检查报告。
