# 加药图规则

## 绘图最小信息

按用户范围保留储存容器、液位、计量泵数量与编号、主要阀门、管路层级、流量显示或仪表、出口目的地。卸料泵、校准柱、压力附件、旁通和控制参数只在本次要求或连接表达需要时展开。

## 数量与显示的区别

分别统计：实物泵数量、SCADA 显示项数量、已确认实物流量计数量、出口数量。

“泵投加量（L/h）”可能是测量、计算或设定显示，不能直接认定每台泵都有一台物理流量计。泵旁与出口旁的显示也可能取同一信号，不能相加成仪表采购数量。证据只有显示时，F 图例写“流量显示点”，备注记录物理表型与安装位置待核实。

用户只要求删除泵旁显示时，连同该层级 F 符号删除；出口显示可保留。不要顺带删掉全部流量信息。

## 储罐合并

一个储罐图形可以代表 3 只实际储罐，但标签必须注明“储罐组，3只合并示意”。对应三套液位或阀门写“×3”，不要让读者理解为一个共享液位计或三阀串联。原资料未确认数量时不自动用3。

## 泵阀与出口连接

- 泵数和出口数分别核对，不要求一泵一路。只有资料或用户确认后才能画固定对应关系。
- 原图连接清楚时保留主阀门、联通、支路与去向。阀门类型未标清时用通用阀门符号，不指定刀闸、止回或驱动型式。
- 交叠管组难以辨认时，可用一个“投加阀组，内部连接简化”的功能区域，明确泵接入点和出口。符号代表阀组时不暗示一只实际阀。
- 不把功能块改成无阀全连通总管，也不由5台泵与4路出口推断第5台为公用备用。
- 用户要求将新增连接纳入简化区域时，扩大区域并分别引出新增出口。框内不画未确认的互通线。
- 新增配套隔离阀若为绘图建议要标“示意”，不能混成已确认采购数量。

## 阶段与新增项目

用户确认两个阶段布置相同后，可复制设备关系，但注明阶段。保留“本阶段1#、2#池”等归属，未确认不改成全厂3#、4#池。

新增设备采用明确“新增”标签和不同颜色，合计数量写成“现有5台＋新增1台”。新增磁混凝1#池与现有磁混凝池必须各自命名。新增出口未知去向时只编号，不猜目标池。

“新增泵和一路出口”不自动包含新增流量计、压力计、液位计、阀门执行器或复杂联锁设计。仅绘本次已要求内容及必要连接；对其他配置保持建议或待核实状态。
