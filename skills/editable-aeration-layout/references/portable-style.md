# 跨平台风格与证据约束

## 绘制前固定参考
生物池优先打开随包 reference-layout.png / biological-pool.png，并检查相应 PPTX 原生对象。必须记录实际打开的路径。不可仅说“已读技能”就自行换成彩色仪表、卡片、三维池或装饰图。参考图只决定样式，不提供本项目设备数量。

## 符号契约（96dpi坐标）
白底；池壁黑色 #171717，线宽1.6～2；空气管亮绿 #00D000，线宽6～8；水流蓝 #4578CE，实心箭头；阀门和空气流量计红 #E83732。DO、MLSS、NH3-N全部为白底黑边圆圈加两条对角线，名称放圈外，不以绿色/紫色实心圆区分仪表。仪表圈直径24～30。调节阀为红色圆圈内交叉线，上接短杆及小方框。气体流量计为红圈红字，默认F；用户指定L时只换字母，保留其他样式。正文优先微软雅黑，标题不超过正文的1.4倍。短标签按实际字体测宽，不使用整池宽文本框。

## 运行环境与交付
工具可以换，视觉契约和原生可编辑性不能随工具换。Codex 可用 artifact-tool；其他平台可用本机支持的原生PPT形状API或OOXML。禁止静默换成整页位图、SVG图片或任意默认图标。缺少字体时选择中文无衬线替代并说明。没有参考附件或无法渲染时明确说明未完成风格比对，不宣称风格一致。

## 绘图必须消费证据记录
每个区域、管段、点位至少记录id、名称、来源、确认状态；每个管径关联具体管段，不能用典型管径填空。D426×10等外径壁厚记法不得改成DN426。缺失设备表时U1～U13不能直接解读为DO或流量计。顶部走道板不自动等于水下隔墙；同一水池跨走道只计一次仪表。多段同名区域先核对是否同一连续工艺区。资料存在矛盾时用清晰图纸+用户确认纠正，不能把先前助手推断当用户确认。

## 检查后交付
先核对工艺区顺序、池组/走道、每条空气支路走向及管径，再逐页核对符号和参考图。允许管线穿过阀件或仪表中心，但不得以“工程图”理由整体关闭所有遮挡检查。新增/建议点位与既有设备分别记录。绘图工具报错修复后重渲染。不能用截图小字“待确认”抵消主体中明确但无证据的完整水路。
