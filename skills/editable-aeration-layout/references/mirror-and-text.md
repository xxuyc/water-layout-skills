# 原生图形镜像与紧凑标签

## 使用用户完成的一侧

先读取 PPT 页面大小、全部图形对象、文字内容和旋转角度，并渲染源文件。按对象 ID 明确源区域、旧目标区域、共享设施和图例。不能仅按坐标中点分类，旋转线的未旋转外框可能跨出区域，设备标签也可能跨出池体边界。

图形左边界为 x，宽度为 w，镜像轴为 c，镜像后 x′ = 2c − x − w。y、w、h 保持不变。先完成镜像，再对整幅图统一缩放和移动。

对非文字图形，将旋转角度取负，并切换水平翻转状态，以处理旋转箭头、斜线和自定义路径。不要只改变外框位置。

对文本仅改变位置，不翻转字形。左对齐标签在镜像后改为右对齐，右对齐改为左对齐，以保留文字与对应设备的距离。区域名称居中对齐保持不变。

重新分配图形 ID 与创建标识。如存在附着连接线或动画，需要同步引用。嵌套组合必须使用理解组合坐标系的方法；本技能附带的脚本只处理独立原生 shape，不支持组合、图片、图表或附着连接线的引用重写。

## 可复用脚本

`scripts/mirror_native_shapes.py` 对明确选定的独立原生形状作镜像，同时保留输入文件和未改动的文件部件。

调用形式：

```text
python scripts/mirror_native_shapes.py input.pptx output.pptx --slide 1 --source-ids 3,4,5 --remove-ids 60,61,62 --axis-px 500 --report mirror-pairs.json
```

这些 ID 只是调用示例。必须从本次文件中读取实际 ID，并先检查有无附着连接线、动画或组合。`--remove-ids` 仅是输出副本中被替换的目标图形，不会修改源文件。脚本不自动推断区域，也不自动调整文本框或版面。

本轮已用真实修改稿验证 74 对对象的镜像位置、尺寸、纵坐标和旋转关系。使用脚本后仍需渲染检查，特别是字体、文字锚点和自定义路径。

## 紧凑文本框

按段落合并文字运行，不能把同一段中不同 run 当作换行。保留有意的 MBBR/填料区等多行结构。

使用实际安装字体测量每行宽度。取最大行宽加少量边距，按行数、字号和行高计算高度。调整时保留原文字的可见位置：居中标签保留水平中心，左对齐保留起点，右对齐保留终点。

嵌入流量计和压力变送器圆圈内的 F/P 文字，其框大小与符号有关，应保持居中。不要给所有文本设置相同的大外框。

## 从这次修订提取的偏好

图内不放独立的布置说明侧栏，说明由 Word 承担。池形尽量放大、图例紧凑集中、设备与文字可编辑。

使用参考 PPT 时，只借用图例、配色、紧凑文字与原生对象结构。脱气区、MBBR、压力变送器和共用出水渠属于 301 项目的用户修订内容，其出现与数量需要由下一项目资料支持。
